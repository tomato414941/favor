# 基本仕様

## 依頼

- 依頼者が内容・金額・公開範囲を指定してリンクを作り、相手に共有する。
- 作成・受諾・納品には登録・ログインが必要。
- 見積もり・打ち合わせ・修正依頼は行わず、表現と仕上がりは作り手に任せる。
- 受諾・納品の期限はリンク作成日から数える。受諾やリンク再発行では延長しない。
- 作り手は納品期限内に再納品できる。
- 受諾前は依頼者が取り消せる。受諾後は作り手のギブアップ、または未納品のまま期限を過ぎるとキャンセルする。

## 依頼リンク

- 受諾前はURLを知る人が、ログインせずに内容・金額を確認し、辞退できる。
- 受諾後は受諾したアカウントだけがリンクを開ける。依頼者は自分の一覧から確認する。
- リンクを再発行すると古いURLは無効になる。辞退・取消・期限切れでもリンクは無効になる。

## 公開範囲

| 設定   | 納品後の公開内容                                       |
| ------ | ------------------------------------------------------ |
| 公開   | 依頼者名・依頼文・作品プレビュー                       |
| 匿名   | 依頼文・作品プレビュー。依頼者名は作り手にも知らせない |
| 非表示 | 一般公開しない                                         |

依頼金額は一般公開しない。納品ファイルのダウンロードは当事者に限る。閲覧注意の依頼は公開一覧に載せない。
非表示でも作り手による外部での作品発表は制限せず、秘密保持や権利譲渡を意味しない。
